# אמגושא · AMGU'SHA

דף נחיתה (landing page) למותג בירת הקראפט **אמגושא**.
אתר סטטי — HTML, CSS ו־JS רגילים, בלי פריימוורק ובלי שלב build.
כל האתר בעברית ובכיוון RTL.

**Live:** https://amgusha-brewery.vercel.app

## הרצה מקומית

```bash
python3 -m http.server 8080   # ואז http://localhost:8080
```

## נכסי המותג

כל התמונות נגזרו מהארט המקורי של המותג בתיקיית `Amgu'sha/`:

- **הלוגו** — הרקע הלבן הוסר ב־threshold, והקובץ נחתך לגבולות התוכן האמיתיים.
- **ראש הלינקס** — חולץ באמצעות **מיפוי רכיבים קשורים** (connected components):
  ראש הלינקס הוא הקומפוננטה הגדולה ביותר, וכל הקומפוננטות האחרות הן אותיות העבריות
  של הכתיב. זה נכון יותר מחיתוך לפי קופסה ידנית, שנשבעת לשבור את הראש או
  להשאיר שברי אותיות.
- הקבצים `(1).png`, `(2).png` ו־`_.png` זהים זה לזה (`md5` זהה) — נעשה שימוש באחד בלבד.
- כל התמונות הוקטנו ל־900px ודחוסו (`quality=80, progressive`) כדי לשמור על משקל העמוד.

## מערכת העיצוב

הפלטה **נדגמה מתווית ה־Pale Ale**, לא נבחרה אקראית:

| תפקיד | צבע |
|---|---|
| קרם (רקע) | `#F4EED3` |
| שזיף | `#732E68` |
| אגוזי | `#B32959` |
| תפוז | `#E9922D` |
| סגול־כהה | `#3A3058` |
| ירוק סגול | `#80A468` |
| שריף | `#DF612C` |
| דיו (טקסט/מסגרת) | `#251327` |

- מסגרות `3px` שחורות, צל קשוח (`6px 6px 0`), כמו הדפס בדיו.
- פסי מוזאיק צבעוניים בראש העמוד ובין הסקשנים.
- **שמשת צבעים מסתובבת** (`.spin`) מאחורי הלוגו — `repeating-conic-gradient`
  בפלטת המותג, סבבה אחת כל 26 שניות (`@keyframes spin`).
- **באנר צועק** (`.section__shout`) מתחת לכותרת הבירות — אנימציית
  `jolt` שקופצת את הבאנר כל 3.6 שניות.
- טיפוגרפיה: **Heebo** (עברי, 900) לכותרות ולגוף, **Archivo Black** לשמות
  הבירות באנגלית, **Space Mono** לטקסטים טכניים.
- אפקט נייר: `feTurbulence` grain + סיביות, `mix-blend-mode: multiply`.
- נגישות: `prefers-reduced-motion` מבטל את כל האנימציות — כולל `spin`
  ו־`jolt` — אך שניהם נשארים גלויים וקריאים, וההטיה נשמרת. טבעת פוקוס
  בולטת, `alt` בעברית לכל תמונה, `dir="rtl"` + `lang="he"` בשורש.

## החלפת תוויות

יש כרגע תווית אמיתית רק ל־Pale Ale. כרטיסי ה־IPA וה־STOUT משתמשים בגליפי SVG
מצוירים. כדי להחליף: שמור את התווית כ־`assets/`, ועדכן את `src` ואת `alt` בתוך
`.card--ipa` / `.card--stout` ב־`index.html`.

## המשחקים

ארבעה משחקים קטנים ב־`games.js`, ללא תלויות. כולם מספרים חלק מהסיפור
ומסתיימים בהערכה גסה. כל אחד נמצא בתוך `index.html` ב־`#games`.

| משחק | מה זה עושה |
|---|---|
| **מלחמת הלינקס** | לוח 3×3. צביים עולים מהבורות — תכו בהם (+1). אחד מכל ארבעה הוא הלינקס עצמה, ופגיעה בה עולה −3 ומזעזע את הלוח. 20 שניות. |
| **מכונת השמשה** | מחוון קצה נע בתוך מסלול; לחצו "עצור!" כדי לעצור. שבעה סבבים, ואזור הירוק **מתכווץ** בכל סבב. התוצאה היא צפיפות (1.000–1.200). |
| **כמה בירה אתה?** | שש שאלות על סוף שבוע, החלטות גדולות, מוזיקה ברכב, תיאור חברים, יום כושל ואי בודד. ארבע תשובות לכל שאלה (א׳/ב׳/ג׳/ד׳), אין תשובה נכונה. האות שנבחרה הכי הרבה קובע את הבירה. |
| **חוזה הלינקס** | חוזה בשישה סעיפים שמתגלה סעיף־סעיף. לחיצה חלקית חושפת סעיף נוסף (ההתקדמות לא נזרקת); לחיצה ארוכה חותמת את הכול. |

## החלקים האחרונים שנוספו

שלושה סקשנים שנוספו אחרי ההשקה הראשונה, באותה מערכת עיצוב (מסגרות `3px`, צל קשוח, הטיות):

| סקשן | מה זה עושה |
|---|---|
| **מניפסט** (`#manifesto`) | רצועה מלאה בסגנון `--violet` עם שלוש שורות גופנות מוטות, כל אחת עם מילה מסומנת בצבע אחר. תחתיהן כרטיס מונו קטן עם שורת חתימה. |
| **הייצור** (`#process`) | ארבעת שלבות ההכנה (מלקוה → ספסד → הרתחה → ביקורת הלינקס) כרשת של ריבועים עם מספר `Archivo Black` בעמודה צבועה, ותגית מונו לכל שלב. מתחתיה רצועת תהילים. |
| **מה לאכול** (`#pairing`) | שישה כרטיסי אכילה — שם המנה, הבירה המתאימה, תיאור ומחיר — עם הערת אלרגנים בסוף. |

- שני הסקשנים החדשים נפתחים מהניווט (`הייצור`, `מה לאכול`).
- `.step` ו-`.dish` משתלמים את דפוס ההטיה של `.card` ו-`.game` (אי־זוגיות + `margin-top`), וב־`560px` ההטיות מתאפסות כמו בשאר העמוד.
- `.step` על מסך צר הופך לעמודה אחת, ומספר השלב עובר לפס למעלה כדי לא לאכוס רוחב.
- `aria-hidden` על ארבעת המספרים — הם דקורטיביים ולא נושאים מידע שאינו בכותרת השלב.
- אין כאן JS חדש: שלושת הסקשנים הם HTML ו־CSS בלבד.

### כיצד נקבעת התוצאה במשחק "כמה בירה אתה?"

כל תשובה מצביעה על אות (`a`/`b`/`c`/`d`), והאות הנבחרת הכי הרבה פעמים קובעת את הבירה.
אין כאן ניקוד מספרי — רק ספירת קולות.

| אות | בירה | מי זה |
|---|---|---|
| א׳ | `WHEAT` — בירת חיטה מרעננת | השקט, הטבע, היציב |
| ב׳ | `LAGER` — לאגר קליל וזורם | הנשמה של החבורה |
| ג׳ | `STOUT` — לילה שחור | העמק הפנימי |
| ד׳ | `IPA` — אמגושה קשוחה | הנועז, הלא שגרתי |

החלטות תכנון שנדרשו לכך ושכדאי לדעת:

- **האותיות מעורבבות בכל הרצה** (`shuffled`, Fisher-Yates). אחרת א׳ תמיד תהיה ראשונה
  וד׳ תמיד אחרונה, והמשתמש ילמד את המיקום ולא את התוכן.
- **`data-l` נושא את האות הלוגית, ו-`.quiz__mark` את האות המוצגת.** ההפרדה הזו
  מונעת מצב שבו התווית הנראית לעין לא תואם את ההצבעה בפועל.
- **תיקון תיקויים** (`TIEBREAK`) נקבע ל־`c → d → a → b`, כלומר העמק הפנימי מנצח.
  הרצה של שיש תיקויים תמיד תחזיר את אותה תוצאה, במקום להשתנות לפי סדר התשובות.
- התוצאה מציגה את הטבלה המלאה (`א׳ 2 · ב׳ 2 · ג׳ 2 · ד׳ 0`) כדי שהמשתמש
  יראה שאין סוד, ומוסיפה שורת חברים בתוך מסגרת מודגשת.
- לחיצה על תשובה אחרי סיום היא no-op (`i >= Q.length`), וכפתור "שאלות אחרות"
  מאפס את הספירה לגמרי.

**הערות מימוש:**

- כל הטיימרים נמוקים באופן מרכזי (`clearAll`) בכל אתחול, כך שמשחקים לא
  מצטברים זה על זה אם המשתמש מתחיל מחדש.
- תנועת המחוון מבוטלת תחת `prefers-reduced-motion`, אך המשחק נשאר **ניתן
  למשחק** — אפשר לעצור ידנית בכל רגע.
- חוזה הלינקס נגיש מהמקלדת: `Enter`/`Space` חותמים מיד, ללא צורך להחזיק.
- שדות `aria-live` על הפלט של כל משחק, וכפתורי הלוח מסומנים `aria-label`.
